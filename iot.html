ห้องเรียน IoT · Internet of Things

สร้างบ้านและห้องเรียนอัจฉริยะ
จากเซนเซอร์ บอร์ด และแอปมือถือ

วางบอร์ด Arduino, ESP32 หรือ Raspberry Pi ลงบนโต๊ะทดลองแบบ 3D มองจากด้านบน ต่อสายเซนเซอร์เข้าขา เขียนกฎ "ถ้า…แล้ว…" แล้วดูสัญญาณวิ่งไปสั่งไฟ พัดลม ปั๊มน้ำ และส่งแจ้งเตือนถึงมือถือ ระบบแปลงกฎเป็นโค้ดจริงให้ดูทุกครั้ง

เริ่มบทที่ 1 ทดลองอิสระ

บทเรียน

เรียงจากง่ายไปยาก แต่ละบทมีโจทย์จากชีวิตจริงและภารกิจที่ระบบตรวจให้ทันที ทำครบได้ XP และเหรียญ

    ก่อนเริ่ม รู้ 3 เรื่องนี้

    Input และ Output

    เซนเซอร์เป็นขาเข้า (Input) บอกบอร์ดว่าเกิดอะไรขึ้น ส่วนไฟ พัดลม และไซเรนเป็นขาออก (Output) ที่บอร์ดสั่งให้ทำงาน

    Digital และ Analog

    สัญญาณดิจิทัลมีแค่ HIGH กับ LOW เช่น มีคน/ไม่มีคน ต่อขา D ส่วนอนาล็อกเป็นตัวเลขต่อเนื่อง เช่น 28°C หรือดินชื้น 45% ต้องต่อขา A

    Cloud และมือถือ

    บอร์ดที่มี Wi-Fi อย่าง ESP32 ส่งค่าขึ้น Cloud ได้ มือถือจึงดูค่า สั่งงาน และรับแจ้งเตือนได้แม้อยู่นอกบ้าน ส่วน Arduino UNO ไม่มี Wi-Fi

    ชิ้นส่วนในห้องทดลอง

    ทุกชิ้นมีโมเดล 3D ในห้องจำลอง กดที่การ์ดเพื่อเปิดโหมดทดลองอิสระพร้อมชิ้นส่วนนั้น
